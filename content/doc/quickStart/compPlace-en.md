# Placing components on the PCB
## Enabling component placement mode
To enable component placement mode on the PCB, click this button

![Component placement mode button](shot-5-stp-1-en.png)

## Changing the grid step
By default, components align to the grid. Let's set a finer grid.
To do this, click this button.

![Changing the grid step](shot-5-stp-2-en.png)

In the Grid step field, enter 0.625 or select 0.625x0.625 from the list of previous grids.

![Changing the grid step](shot-5-stp-3-en.png)

Click OK to finish.

![Finishing grid step change](shot-5-stp-4-en.png)

## Selecting a component for placement
Hover the mouse cursor over a component and press the left mouse button.

![Selecting a component for moving](shot-5-stp-5-en.png)

Move the mouse, the component will move with the mouse.

![Moving component](shot-5-stp-6-en.png)

## Changing component orientation
To quickly change orientation by 90 degrees clockwise, press the F2 key.

![Changing component orientation](shot-5-stp-7-en.png)

## Placing components
To place the component at the current position, press the left mouse button.

![Placing component](shot-5-stp-8-en.png)

![X1](shot-5-stp-9-en.png)

Press the left mouse button and move the component.

![X1 moving](shot-5-stp-10-en.png)

![X1 rotation](shot-5-stp-11-en.png)
