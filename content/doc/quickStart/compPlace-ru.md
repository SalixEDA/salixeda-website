# Расстановка компонентов на плате
## Включение режима расстановки компонентов
Чтобы включить режим расстановки компонентов на плате нажмите такую кнопку

![Кнопка режима расстановки компонентов](shot-5-stp-1-ru.png)

## Изменение шага сетки
По умолчанию компоненты выравниваются по сетке. Установим более мелкую сетку.
Для этого нажмите на эту кнопку.

![Изменение шага сетки](shot-5-stp-2-ru.png)

В поле Шаг сетки введите 0.625 или выберите из списка предыдущих сеток 0.625х0.625.

![Изменение шага сетки](shot-5-stp-3-ru.png)

Нажмите ОК для завершения.

![Завершение изменения шага сетки](shot-5-stp-4-ru.png)

## Выбор компонента для расстановки
Наведите курсор мыши на компонент и нажмите левую кнопку мыши.

![Отметка компонента для перемещения](shot-5-stp-5-ru.png)

Перемещайте мышь, компонент будет перемещаться вместе с мышью.

![Перемещение компонента](shot-5-stp-6-ru.png)

## Смена ориентации компонента
Для быстрой смены ориентации на 90 градусов по часовой стрелке нажмите клавишу F2.

![Смена ориентации компонента](shot-5-stp-7-ru.png)

## Расстановка компонентов
Чтобы поставить компонент в текущем положении нажмите левую кнопку мыши.

![Установка компонента](shot-5-stp-8-ru.png)
