# Трассировка соединений
## Включение режима трассировки соединений
Чтобы включить режим трассировки соединений нажмите такую кнопку.

![Трассировка](shot-6-stp-1-ru.png)

## Установка сетки для трассировки
По умолчанию узлы изломов трасс выравниваются по сетке. Установим более мелкую сетку.
Для этого нажмите на эту кнопку.

![Трассировка](shot-6-stp-2-ru.png)

В поле Шаг сетки введите 0.625 или выберите из списка предыдущих сеток 0.625х0.625.

![Трассировка](shot-6-stp-3-ru.png)

Нажмите ОК для завершения.

![Трассировка](shot-6-stp-4-ru.png)

## Начало трассы
Перемещайте мышь. Одновременно система будет предлагать точку начала трассы.
Она показывает эту точку квадратиком.

![Трассировка](shot-6-stp-5-ru.png)

Подведите мышь к первому контакту разъема X1.

![Трассировка](shot-6-stp-6-ru.png)

Нажмите левую кнопку мыши, чтобы начать трассу с предложенного места.

![Трассировка](shot-6-stp-7-ru.png)

## Смена угла излома трассы
Разумный режим предлагает вариант завершения трассы. При этом трасса строится с
изломами 90 градусов.

![Трассировка](shot-6-stp-8-ru.png)

Нажмите эту кнопку, чтобы сменить угол изломов на 45 градусов.

![Трассировка](shot-6-stp-9-ru.png)

## Использование разумного режима для завершения трассы
Переместите мышь таким образом, чтобы завершение трассы было таким, как на рисунке.

![Трассировка](shot-6-stp-10-ru.png)

Нажмите среднюю кнопку мыши, чтобы принять предложение "разумного режима".

![Трассировка](shot-6-stp-11-ru.png)

## Смена слоя трассировки
Нажмите левую кнопку мыши, чтобы начать трассу. Эта трасса не проходит по
одному слою, поэтому нужно перейти на нижний слой.

![Трассировка](shot-6-stp-43-ru.png)

Нажмите на эту кнопку, чтобы открыть список доступных слоев.

![Трассировка](shot-6-stp-44-ru.png)

Выберите bottom

![Трассировка](shot-6-stp-45-ru.png)

При этом добавляет переходное отверстие.

![Трассировка](shot-6-stp-46-ru.png)

И разумный режим работает уже на нижнем слое.

![Трассировка](shot-6-stp-47-ru.png)

Нажмите среднюю кнопку мыши, чтобы принять предложение "разумного режима".
Нажмите правую кнопку мыши, чтобы завершить трассировку.

![Трассировка](shot-6-stp-48-ru.png)
