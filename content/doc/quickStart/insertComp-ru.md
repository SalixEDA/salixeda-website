# Вставка компонентов из библиотеки в схему
## Включение режима вставки компонентов
Для включения режима вставки компонентов нажмите такую кнопку.

![Кнопка режима вставки компонентов в схему](screen13-ru.png)

## Поиск компонента по базе
При этом появляется диалоговое окно поиска компонентов по библиотеке. В поле объекта
для поиска введите "xpt" и нажмите кнопку Найти.

![Ввод имени компонента для поиска и кнопка Найти](screen14-ru.png)

Появляется список компонентов, подходящих под строку поиска. Выберите в этом списке
микросхему XPT8871.

![Выбор компонента в списке поиска](screen15-ru.png)

В нижней части окна поиска появятся предварительный просмотр для выбранного компонента:
его список секций, а изображение текущей секции будет показано в окне Символ. В окне
корпус будет показано графическое изображение корпуса компонента. В окне 3D - объемное
изображение корпуса компонента. 

### Выбор секции компонента в списке секций
Выберите нужную секцию в списке доступных секций компонента.
Если у компонента одна секция, то она выбирается автоматически.

![Выбор секции компонента в списке секций](screen16-ru.png)

Нажмите ОК для вставки выбранной секции выбранного компонента в схему. 

![Завершение выбора компонента](screen17-ru.png)

## Задание положения компонента на схеме
Перемещайте мышь по полю листа схемы. При этом компонент перемещается вслед за мышью.

![Задание положения компонента на схеме](screen18-ru.png)

Когда определите нужное положение компонента, нажмите левую кнопку мыши. При этом
компонент вставляется в схему и можно определять положение для следующего экземпляра
компонента.

Нажмите правую кнопку мыши для прекращения вставки текущего компонента и перехода
к возможности выбора другого компонента.

![Вставка компонента в схему](screen19-ru.png)

## Поиск и вставка конденсатора
В поле поиска компонента введите "0603 1uf". Данный запрос означает,
что будут найдены все компоненты, в названии или параметрах которых есть 0603 и 1uf
одновременно. 

![Ввод имени для поиска конденсатора](screen20-ru.png)

Появится большой список, в котором будут конденсаторы с емкостью 0.1uf,
0.01uf и 1uf. Это нормально и происходит потому, что поиск осуществляется по части
имени или параметра. Имейте это ввиду при задании шаблона поиска.
Найдите в списке конденсатор именно с емкостью 1uf и кликните по нему левой кнопкой
мыши.

![Выбор конденсатора 1uf из списка найденных конденсаторов](screen21-ru.png)

Нажмите кнопку ОК для вставки конденсатора в схему.

![Вставка конденсатора](screen23-ru.png)

### Определение размещения конденсатора
Перемещайте мышь для определения нужного положения конденсатора. Нажмите левую кнопку
мыши для вставки конденсатора в схему.

![Определение размещения конденсатора](screen24-ru.png)

### Ориентация компонента
Можно ввести несколько экземпляров одного компонента. В данном случае базовая ориентация
компонента не совпадает с желаемой. Измените ориентацию компонента с помощью кнопок
изменения ориентации.

![Изменение ориентации конденсатора](screen29-ru.png)

Определите местоположение для конденсатора и нажмите левую кнопку мыши.

![Вставка второго экземпляра конденсатора](screen30-ru.png)

Определите местоположение для третьего экземпляра конденсатора и нажмите левую кнопку
мыши.

![Вставка третьего экземпляра конденсатора](screen31-ru.png)

Все экземпляры конденсатора с номиналом 1uf вставлены. Нажмите правую кнопку мыши
для возврата к выбору компонента.

![Все экземпляры конденсатора вставлены](screen32-ru.png)

## Поиск и вставка резистора
В поле поиска введите "0603 1k" и нажмите кнопку Искать.

![Ввод в поле поиска резистора](screen33-ru.png)
 
 Среди всех найденных резисторов выбираем резистор с номиналом 1кОм.
 
![Ввод в поле поиска резистора](screen34-ru.png)

И нажимаем кнопку ОК для размещения и вставки.

![Ввод в поле поиска резистора](screen35-ru.png)

Ориентация для резистора сохранилась от предыдущего компонента. Она не правильная.
Меняем ориентация на правильную.

![Смена ориентации резистора](screen36-ru.png)

Укажите местоположение для резистора и нажмите левую кнопку мыши. Поскольку резистор
с таким номиналом нужен один, то затем нажмите правую кнопку мыши для перехода к поиску
другого номинала.

![Вставка резистора](screen37-ru.png)

## Поиск и вставка резистора с номиналом 4.7кОм 
В поле поиска введите "0603 4.7k" и нажмите Найти.

![Поиск резистора с номиналом 4.7кОм](screen38-ru.png)

В списке найденных резисторов выберите резистор с номиналом 4.7кОм.

![Выбор из списка резистора с номиналом 4.7кОм](screen39-ru.png)

Нажмите ОК для размещения резистора в схеме.

![Завершение выбора резистора](screen40-ru.png)

Перемещайте мышь, чтобы указать местоположение резистора на схеме. Нажмите левую кнопку
мыши для вставки резистора в схему.

![Вставка резистора](screen41-ru.png)

Нажмите правую кнопку мыши для возвращения к поиску следующего компонента.

![Завершение вставки резистора](screen42-ru.png)

## Поиск и вставка разъема
В поле поиска компонента введите "pls3" и нажмите Найти.

![Поиск разъема](screen43-ru.png)

В появившемся списке подходящих разъемов выберите connector pls3

![Выбор разъема из списка](screen44-ru.png)

Для вставки компонента в схему нажмите ОК

![Завершение поиска разъема](screen45-ru.png)

### Зеркальность компонента
Базовое изображение разъема не подходит - разъем имеет неверное направление.

![Базовое направление разъема](screen46-ru.png)

Ориентацией это не исправить (разъем будет вверх ногами). Здесь требуется зеркальное
отображение компонента. Измените зеркальность компонента этой кнопкой.

![Зеркальность разъема](screen47-ru.png)

Укажите расположение разъема на схеме и нажмите левую кнопку мыши.

![Указание расположения разъема](screen48-ru.png)

Нажмите правую кнопку мыши для возврату к поиску компонентов.

![Завершение вставки разъема](screen49-ru.png)

## Завершение режима вставки компонентов
Для прекращения вставки компонентов нажмите правую кнопку мыши.
При этом появляется диалоговое окно поиска компонентов. Нажмите в нем Отмена. Это
завершит режим вставки компонентов.

![Завершение вставки компонентов](screen60-ru.png)
