# Routing connections
## Enabling routing mode
To enable routing mode, click this button.

![Routing](shot-6-stp-1-en.png)

## Setting the routing grid
By default, route vertex nodes align to the grid. Let's set a finer grid.
To do this, click this button.

![Routing](shot-6-stp-2-en.png)

In the Grid step field, enter 0.625 or select 0.625x0.625 from the list of previous grids.

![Routing](shot-6-stp-3-en.png)

Click OK to finish.

![Routing](shot-6-stp-4-en.png)

## Starting a trace
Move the mouse. At the same time, the system will suggest a starting point for the trace.
It shows this point with a small square.

![Routing](shot-6-stp-5-en.png)

Move the mouse to the first pin of connector X1.

![Routing](shot-6-stp-6-en.png)

Press the left mouse button to start the trace from the suggested location.

![Routing](shot-6-stp-7-en.png)

## Changing the trace vertex angle
Smart mode suggests a way to complete the trace. The trace is built with
90-degree vertices.

![Routing](shot-6-stp-8-en.png)

Click this button to change the vertex angle to 45 degrees.

![Routing](shot-6-stp-9-en.png)

## Using smart mode to complete the trace
Move the mouse so that the trace completion looks like the one in the figure.

![Routing](shot-6-stp-10-en.png)

Press the middle mouse button to accept the "smart mode" suggestion.

![Routing](shot-6-stp-11-en.png)

## Changing the routing layer
Press the left mouse button to start the trace. This trace does not stay on
one layer, so you need to switch to the bottom layer.

![Routing](shot-6-stp-43-en.png)

Click this button to open the list of available layers.

![Routing](shot-6-stp-44-en.png)

Select bottom

![Routing](shot-6-stp-45-en.png)

This adds a via.

![Routing](shot-6-stp-46-en.png)

And smart mode now works on the bottom layer.

![Routing](shot-6-stp-47-en.png)

Press the middle mouse button to accept the "smart mode" suggestion.
Press the right mouse button to finish routing.

![Routing](shot-6-stp-48-en.png)
