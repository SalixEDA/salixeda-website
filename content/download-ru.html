Установка

Для установки программы используется специальный установщик небольшого размера. Скачайте этот установщик для вашей операционной системы и запустите. Установщик самостоятельно скачивает все необходимые архивы, распаковывает их и регистрирует в меню Пуск.

Windows

  1. Скачайте файл SalixEDA.exe
  2. Запустите установщик
  3. Следуйте инструкциям мастера установки
  4. Программа появится в меню "Пуск"

Linux

  1. Скачайте файл SalixEDA
  2. Сделайте его исполняемым: chmod +x SalixEDA
  3. Запустите: ./SalixEDA
  4. Следуйте инструкциям мастера установки
  5. Программа появится в меню "Пуск" или аналоге
