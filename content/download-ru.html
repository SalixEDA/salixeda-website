Системные требования

Минимальные

  • Windows 10/11 или Linux с glibc 2.28+
  • Процессор: 2-ядерный, 2.0 GHz
  • Оперативная память: 2 ГБ
  • Место на диске: 500 МБ
  • Разрешение экрана: 1280×720

Рекомендуемые

  • Windows 10/11 64-bit или современный дистрибутив Linux
  • Процессор: 4-ядерный, 3.0 GHz+

  • Место на диске: 2 ГБ (для библиотек)
  • Разрешение экрана: 1920×1080+
  • Видеокарта с поддержкой OpenGL 3.3+ (для 3D-просмотра)

Установка

Windows

  1. Скачайте файл .exe
  2. Запустите установщик
  3. Следуйте инструкциям мастера установки
  4. Программа появится в меню "Пуск"

Linux (AppImage)

  1. Скачайте файл .AppImage
  2. Сделайте его исполняемым: chmod +x CircuitCAD-*.AppImage
  3. Запустите: ./CircuitCAD-*.AppImage
