Project repositories on GitHub are now public

The planned technical preparation of the SalixEDA CAD system source codes has been completed. All official project repositories have been migrated from private to public status.

A global profile containing a complete ecosystem map is now available on the organization's main page. Currently, two key repositories are open for inspection and building: the core application (written in C++20 and Qt6) and the official website source code.

The remaining six private repositories, including component libraries, plugins, and related tools, will be made public as soon as they are fully prepared. Direct links to the source code have been integrated into the website's download section.
