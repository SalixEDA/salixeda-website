Репозитории проекта на GitHub сделаны публичными

Завершена плановая техническая подготовка исходных кодов CAD-системы SalixEDA к публикации. Все официальные репозитории проекта переведены из приватного статуса в публичный.

На главной странице созданной организации теперь доступен служебный профиль с общей картой экосистемы. На данный момент для свободного изучения и сборки открыты два ключевых репозитория: ядро самой программы (написанное на C++20 и Qt6) и исходный код официального сайта.

Остальные шесть приватных репозиториев, включающие библиотеки компонентов, плагины и сопутствующие инструменты, будут открываться по мере их окончательной готовности к публикации. Прямые ссылки на исходный код добавлены на сайт в раздел скачивания.
