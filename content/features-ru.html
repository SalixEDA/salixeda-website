Возможности SalixEDA

SalixEDA — интегрированная система проектирования электроники, ориентированная на быструю разработку и повторное использование решений.

Ключевые возможности

Единый файл проекта

Проект представляет собой единое целое: схема, компоненты и печатная плата хранятся в одном файле.

Для переноса проекта достаточно скопировать один файл.

Компоненты "замораживаются" внутри проекта и не изменяются при обновлении библиотек.

При необходимости компоненты можно обновить с возможностью разрешения конфликтов.

Сильносвязанная схема и плата

Схема и печатная плата синхронизируются автоматически в реальном времени.

Добавление компонентов и цепей мгновенно отражается на плате.

Изменения в схеме не требуют дополнительных операций синхронизации.

Это позволяет быстро вносить изменения во время трассировки.

Гибкая система библиотек компонентов

Локальная библиотека автоматически пополняется компонентами из открываемых проектов.

Компоненты можно создавать прямо в процессе проектирования.

Каждая версия компонента сохраняется и отслеживается.

При появлении новой версии компонента в библиотеке такие компоненты подсвечиваются в проекте.

Поддерживается автоматическая синхронизация:

  • с глобальной публичной библиотекой
  • с приватным облаком пользователя

Приватное облако позволяет синхронизировать компоненты между компьютерами и работать в команде.

Библиотеку можно переносить простым копированием файлов.

Система авторства компонентов

Каждый компонент имеет автора и подписывается уникальным идентификатором.

Поддерживается публикация компонентов в глобальной библиотеке.

Доступна система рейтингов и обратной связи по качеству компонентов.

Интегрированная среда разработки

Все инструменты доступны в одной программе:

  • редактор схем
  • редактор печатных плат
  • редактор символов
  • редактор корпусов
  • редактор компонентов
  • редактор 3D моделей
  • просмотр платы в 3D

Удобное редактирование

Поддерживается одновременная работа с несколькими проектами.

Возможен запуск нескольких экземпляров программы.

Доступны групповые операции:

  • перемещение
  • копирование
  • вращение
  • удаление

Используются "умные" режимы редактирования, упрощающие выполнение типовых операций.

Создание компонентов

Встроенные мастера упрощают создание:

  • символов
  • корпусов
  • компонентов
  • 3D моделей

3D моделирование

Встроенный параметрический редактор 3D моделей компонентов.

Поддерживается импорт моделей в форматах VRML и STL.

Производство

Экспорт в GERBER доступен без дополнительных инструментов.

Общие свойства

  • открытый исходный код
  • кроссплатформенность (Windows, Linux)
  • многоязычный интерфейс
