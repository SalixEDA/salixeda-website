Возможности SalixEDA

SalixEDA — интегрированная система проектирования электроники, ориентированная на быструю разработку и повторное использование решений.

Единый файл проекта

Проект представляет собой единое целое: схема, компоненты и плата хранятся в одном файле. Это упрощает перенос и хранение — достаточно скопировать один файл.

Компоненты фиксируются внутри проекта. Изменения в библиотеке не влияют на уже завершённые проекты. При необходимости компоненты можно обновить с разрешением конфликтов.

Связь схема и плата

Схема и печатная плата синхронизируются автоматически в реальном времени. Добавление компонентов и цепей мгновенно отражается на плате.

Это позволяет вносить изменения прямо в процессе трассировки, не выполняя дополнительных операций синхронизации.

Библиотеки компонентов

В системе используется комбинированная модель хранения компонентов, включающая локальную библиотеку, глобальное хранилище и приватное облако.

Локальная библиотека автоматически пополняется компонентами из открываемых проектов. Достаточно открыть чужой проект — и все используемые в нем компоненты станут доступны в библиотеке.

Компоненты можно создавать прямо в процессе проектирования. После создания компонент фиксируется и сохраняется в библиотеке с указанием версии (по времени создания).

Система отслеживает изменения в библиотеке автоматически: при добавлении или копировании файлов извне новые компоненты обнаруживаются и регистрируются без дополнительных действий пользователя.

Глобальное хранилище представляет собой публичную библиотеку компонентов, доступную всем пользователям. В нее попадают компоненты, опубликованные их авторами.

Каждому пользователю автоматически предоставляется приватное облако, которое синхронизируется с локальной библиотекой.

Приватное облако позволяет:

  • синхронизировать компоненты между разными компьютерами
  • работать из разных мест (дом, работа и т.п.)
  • организовать совместную работу

Для совместной работы достаточно передать идентификатор облака — после этого библиотеки участников будут автоматически синхронизироваться между собой практически в реальном времени.

Фрагменты и типовые решения

Можно создавать библиотеку фрагментов — готовых схемных решений — и повторно использовать их в проектах.

При вставке компонента система может предложить готовый фрагмент с его использованием.

Расчет схем

В схему можно встраивать расчетные формулы и связывать их с параметрами компонентов.

Это позволяет автоматически рассчитывать номиналы и упрощает проектирование.

Одна схема — несколько плат

В рамках одного проекта можно использовать одну схему для нескольких печатных плат.

На схеме задаются регионы, которым соответствуют отдельные платы.

Компоненты, попавшие в регион, автоматически размещаются на соответствующей плате.

Публикация и обмен

Фрагменты можно экспортировать в текстовый формат, который вставляется в HTML-страницу.

Пользователь может скопировать такой фрагмент прямо из браузера и вставить его в проект без скачивания файлов.

Редактирование

Поддерживается работа с несколькими проектами и окнами одновременно.

Доступны групповые операции и "умные" режимы редактирования, упрощающие выполнение типовых действий.

Расстановка компонентов

В процессе размещения компонентов на плате можно выбирать их прямо из схемы.

Это ускоряет работу и уменьшает количество ошибок.

Трассировка

В системе отсутствует классический автоматический трассировщик. Основной упор сделан на удобство и скорость ручной трассировки.

Используется полуавтоматический режим: пользователь начинает прокладывать дорожку, а система предлагает вариант её завершения.

После каждого движения курсора предлагаемый вариант автоматически пересчитывается. На экране одновременно отображаются:

  • трасса, прокладываемая пользователем
  • вариант завершения, предлагаемый системой

Пользователь может принять предложенный вариант или продолжить трассировку вручную. Такой подход позволяет сохранить полный контроль над разводкой и при этом значительно ускоряет процесс.

Поддерживаются многослойные печатные платы:

  • до 30 слоев
  • сквозные переходные отверстия
  • глухие переходные отверстия

Правила трассировки

В системе используются правила трассировки, определяющие зазоры и другие ограничения.

Правила задаются на двух уровнях:

  • общие правила для всей платы
  • индивидуальные правила для конкретных цепей

Если для цепи не заданы собственные правила, используются правила платы.

Правила автоматически соблюдаются системой и не могут быть нарушены при трассировке.

3D моделирование

Встроенный параметрический редактор позволяет создавать 3D модели компонентов.

Поддерживается импорт моделей (VRML, STL).

Производство

Система предоставляет все необходимые данные для производства печатных плат и сборки устройств.

Поддерживается экспорт:

  • GERBER — для изготовления печатных плат
  • ASM — входной файл автоматического установщика компонентов

Формируется документация проекта:

  • BOM (перечень элементов)

Общие возможности

  • открытый исходный код
  • кроссплатформенность (Windows, Linux)
  • многоязыковая поддержка интерфейса
