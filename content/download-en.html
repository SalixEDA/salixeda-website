Installation

A special small-sized installer is used to install the program. Download this installer for your operating system and run it. The installer independently downloads all necessary archives, extracts them and registers them in the Start menu.

Windows

  1. Download the SalixEDA.exe file
  2. Run the installer
  3. Follow the installation wizard instructions
  4. The program will appear in the Start menu

Linux

  1. Download the SalixEDA file
  2. Make it executable: chmod +x SalixEDA
  3. Run it: ./SalixEDA
  4. Follow the installation wizard instructions
  5. The program will appear in the Start menu or its equivalent
